# 手机适配报告

目标：iPhone16Pro，iOS27.0.1，轻松签安装。

## 用户报告的故障

- 预期：横屏画面易于操作，辅助菜单中文，存在圆形移动方向盘。
- 实际：截图显示场景过于宽空，辅助按钮出现NO TEXT FOUND，没有圆形方向盘。
- 位置：地牢内GameScene，旧版辅助按钮。
- 复现：安装初版辅助IPA，横屏进入地牢。

## 原因与修复

翻译键原来为wndassist.*，实际Messages使用windows.wndassist.*；已通过真实资源加载器核查全部中文菜单键。原版只提供点格子移动，没有圆形触控盘；新增TouchStickState与TouchJoystick，接入CellSelector。画面采用横屏原生宽高比，不拉伸图像；增加角色默认缩放并使用可容纳的最大UI缩放。完整保留UIKit报告的安全区，修正工具栏宽度未扣除左边距的问题。

方向盘是八方向的回合制控制，并不把原游戏改成实时动作游戏。手指中心小幅移动不走路；拖动持续移动，松手、取消、切后台或打开菜单停止。第二根手指不能夺走已捕获的方向盘触控。碰到敌人时走原游戏交互/攻击流程。

辅助按钮可拖动到安全区内任意位置并保存，隐藏不影响右上角游戏菜单的恢复入口。菜单可滚动，分别提供角色/地图缩放和界面缩放；界面缩放有安全上限以免裁切。
