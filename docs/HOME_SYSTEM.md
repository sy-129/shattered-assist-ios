# 独立家园指南与实现范围

## 进入与返回

首页点“独立家园”，或在地牢角色可操作时从右上角游戏菜单/辅助菜单进入。进入前保存地牢并停止地牢角色线程；返回后重建地牢画面，保留角色、楼层、生命和位置。家园按游戏槽位单独保存，同一槽位的新冒险继续使用该槽位的家园。首页未选择槽位时使用槽位1。

## 地图与中文操作

地图26×18格，有住宅、成年伴侣林岚、马厩、12块农田、水井、池塘和林地。使用圆形方向盘八方向移动，地图点击相邻格也可走动，建筑和池塘阻挡移动，斜向不能穿墙角。“附近互动”按位置打开家庭/农牧操作，“家园管理”可直接访问所有操作与规则。所有新UI使用中文。

## 时间、婚姻与孩子

只有“休息一天”推进家园日，走动、菜单和真实时间不会自动推进。主人公和伴侣设定为成年人；家庭计划只面向成年伴侣，不提供子女恋爱入口。

每天交谈一次关系+8；每天赠送5粮食一次关系+12。关系60可以结婚；已婚且关系80、准备20粮食且有房舍空间可计划孩子，三个家园日后新成员到来；计划不能叠加。房舍1/2/3级分别容纳1/2/3名孩子，扩建每次20粮食与10木材。

孩子出生时成长日龄0；0–2日婴儿，3–11日儿童，12–17日少年，18日起成年子女。每日照料每位消耗2粮并提升心情，未照料心情下降；成年子女每日贡献2粮。成长速度是游戏日规则，不模拟真实孕期或人类年龄。

## 作物与生态

12块田，播种每块耗1种子；需足够水分并生长3日成熟，收获每块6粮和2种子。水井可给农田与全部动物补水。每12日换季，48日完整循环；雨天补水，冬季停止作物和草地生长。草地被放牧消耗，并按天气与季节恢复。

三个物种为马、鸡、兔，初始各一对；成年门槛分别6/3/4日，寿命上限分别160/60/75日。动物每日消耗食物和水，附近草地与池塘可补充；不足会损失健康，健康归零或超过寿命离开生态。健康、饱食、饮水充足的成年异性同种动物配对繁殖，马待产5日，鸡兔3日；幼崽需要成长，族群上限24只。健康饱食的成年母鸡每日产1粮。这里的鸡出生统一表示幼崽事件，没有独立可拾取蛋物品。

群体喂养每只2粮，补水免费。地图上的动物有轻微待机与马匹帧动画，动物实际位置、需求、繁殖等按家园日更新。生态不包含捕食链、遗传模型、多人联机或真实时间离线推演。

## 坐骑与打击动画

成年马健康≥30、食物和水≥20、亲密度≥40即可骑乘；照料花2粮并改善健康与关系。家园骑乘时移动间隔从0.18秒减为0.10秒；地牢角色原有速度乘1.25，并显示跟随马匹。状态无效或马离开生态后自动下马。

挥砍使用CC0五帧13×13像素特效，随攻击方向旋转缩放；保留原英雄攻击动画与完成回调，不改变回合制战斗、伤害时点或法杖逻辑。这是2D像素动作效果，不是3D骨骼模型。

## 存档与验证

文件：assist-home-v1-slot-N.dat 及 .bak。结构带版本与长度/数值校验；不能解析时先尝试备份，双文件损坏明确报错，不生成新档覆盖。写入复用原游戏临时文件机制。

自动检查25项，其中家园12项模拟检查与2项真实文件持久化检查；包含200日族群上限、生产与生长、婚姻条件、重复操作、养育、日程重载确定性、损坏恢复、槽位隔离。

桌面图形检查实际运行HomeScene与GameScene，用触摸事件进入原输入分发，验证方向盘移动、按钮拖动不误打开、隐藏状态、地牢→家园→地牢、角色生命/位置保持、实际Hero.speed骑乘25%加成和场景渲染。运行入口：

```sh
./gradlew -PiosOnly -PdesktopPreview :desktop:homeRenderSmoke
```

需可用图形显示与OpenGL；Linux可用独立虚拟X显示。输出与合成测试存档位于build/render-check；不写入个人游戏存档。该检查不代替iPhone16Pro/iOS27.0.1的安装、触摸、安全区和后台切换实测。
